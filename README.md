# Ziddi Mumbaikar Website

A modern, community-focused website for Ziddi Mumbaikar - a Mumbai-based NGO and citizen movement dedicated to creating positive social impact through grassroots action.

## 🌟 Project Overview

This website serves as the digital hub for Ziddi Mumbaikar, showcasing their community-driven initiatives and providing platforms for citizen engagement. The site emphasizes trust-building, real impact demonstration, and easy volunteer onboarding.

## 🎯 Key Features

- **Hero Section**: Bold messaging with clear call-to-action buttons
- **About Us**: Mission-driven content highlighting citizen-led approach  
- **What We Do**: Service showcase with 6 key community initiatives
- **Impact Metrics**: Statistics demonstrating real community impact
- **Gallery**: Visual documentation of community work and events
- **Volunteer/Help Forms**: Dual-purpose engagement with tab switching
- **Responsive Design**: Mobile-first approach optimized for all devices
- **SEO Optimized**: Semantic HTML structure for better search visibility

## 🚀 Tech Stack

- **Framework**: Next.js 14 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS with custom color palette
- **Fonts**: Google Fonts (Poppins, Montserrat)
- **Images**: Next.js Image optimization
- **Deployment Ready**: Configured for modern hosting platforms

## 🎨 Design System

### Colors
- **Primary Orange**: `#f0750a` (Saffron accent color)
- **Navy Blue**: `#0c1016` (Primary dark color)
- **White**: Clean backgrounds and contrast
- **Gray Variants**: Supporting text and subtle backgrounds

### Typography
- **Display Font**: Montserrat (headings, bold statements)
- **Body Font**: Poppins (readable content, forms)
- **Font Weights**: 300-900 range for design flexibility

### Design Principles
- Bold and authentic aesthetic
- Action-oriented messaging
- Trust-building through transparency
- Indian NGO visual language
- Strong contrast and readability

## 📱 Sections & Components

### 1. Hero Section
- Full-screen impact with Mumbai cityscape background
- Primary headline: "Ziddi Mumbaikar"
- Subheading: "For a Cleaner, Safer, Stronger Mumbai"
- Three prominent CTAs: Join, Request Help, Donate

### 2. About Us
- Two-column layout with content and placeholder image
- Mission-focused messaging
- Key values highlighting citizen-led action
- Authentic, grounded copy

### 3. What We Do
- Six service cards with icons and descriptions
- Services include: Cleanliness drives, Health campaigns, Emergency support, Women's safety, Local assistance, Environmental action
- Hover effects and "Learn More" CTAs

### 4. Impact Section
- Dark navy background for contrast
- Four key statistics with large numbers
- Circular design elements
- Call-to-action for next community drive

### 5. Gallery
- Grid layout with 8 community work examples
- Category tags for different types of initiatives
- Placeholder images with descriptive text
- "View Complete Gallery" CTA

### 6. Volunteer/Help Section
- Tabbed interface switching between volunteer and help forms
- Comprehensive volunteer registration form
- Help request form with urgency levels
- Information panel with benefits and emergency contact

### 7. Footer
- Complete contact information
- Social media links
- Quick navigation
- Legal disclaimers and transparency messaging

## 🛠 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone [repository-url]
   cd ziddi-mumbaikar-website
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run development server**
   ```bash
   npm run dev
   ```

4. **Open in browser**
   Navigate to `http://localhost:3000`

## 📝 Available Scripts

## 🎨 Content Strategy

### Messaging Tone
- **Bold & Authentic**: Direct communication, no corporate jargon
- **Action-Oriented**: Focus on doing, not just talking
- **Community-Focused**: "We" language, citizen perspective
- **Trustworthy**: Transparent about impact and operations

### Visual Strategy
- **Real Photos**: Community work, Mumbai streets, volunteers in action
- **Strong Typography**: Clear hierarchies, readable fonts
- **Color Psychology**: Orange for energy/action, Navy for trust/stability
- **Accessibility**: High contrast, readable sizes, semantic HTML
