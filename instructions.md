- Build trust
- Show real on-ground impact
- Encourage volunteering, support, and help requests

Target audience:
- Mumbai citizens
- Local volunteers
- People needing community help (cleanliness, fogging, ambulance, events)

Tone & Style:
- Bold, grounded, authentic
- Action-oriented, not corporate
- Indian NGO aesthetic (real photos, strong typography)

Design Guidelines:
- Clean layout with strong headings
- Black / dark navy base
- White background sections
- Accent color: saffron/orange
- Large readable fonts (Poppins / Montserrat style)
- Use real-life imagery placeholders (community work, Mumbai streets)

Pages & Sections:

1. Home Page
   - Hero section with headline:
     "Ziddi Mumbaikar"
     "For a Cleaner, Safer, Stronger Mumbai"
   - CTA buttons:
     "Join the Movement"
     "Request Help"
     "Donate / Support"
   - Background image: Mumbai city or volunteers in action

2. About Us
   - Mission-driven content
   - Focus on citizen-led action
   - Explain local impact and grassroots approach

3. What We Do
   - Card-based layout with icons and short descriptions:
     - Cleanliness Drives
     - Fogging & Health Campaigns
     - Ambulance & Emergency Support
     - Women & Community Events
     - Local Area Assistance

4. Impact Section
   - Large bold statistics (numbers-based trust):
     - Drives conducted
     - People impacted
     - Areas covered
     - Volunteers onboarded

5. Gallery
   - Grid or masonry layout
   - Realistic photo placeholders (before/after, volunteers, events)

6. Volunteer / Request Help
   - Two-column layout:
     - Volunteer form (name, phone, area, interest)
     - Help request form (location, help type, contact)

7. Footer
   - Logo
   - Short mission statement
   - Contact details
   - Social media icons
   - Simple disclaimer

Technical Preferences:
- Responsive, mobile-first
- Accessible (good contrast, readable fonts)
- SEO-friendly structure
- Clean semantic HTML
- Use Tailwind CSS or modern CSS utility approach
- Use placeholder images and dummy content where required

Output:
- Generate a complete homepage layout
- Include component structure
- Write realistic copy (not lorem ipsum)
- Ensure production-quality UI/UX
